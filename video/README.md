# Process Video Workspace

Use this folder for the one-minute vertical process-video workstream.

## Expected Contents

- Storyboard and script.
- HyperFrames project and source assets.
- Licensed audio records.
- Review notes and media-probe results.
- Final 1080 × 1920 H.264/AAC MP4 under `exports/`.

Target a runtime of 55–60 seconds and keep the upload-ready export below 50 MB when practical.

For URL submission, copy the approved final file to:

`landing-page/public/submission/process-video.mp4`

After the Vercel deployment, it will be available at:

`/submission/process-video.mp4`

Do not commit dependency caches, temporary renders, unlicensed media, credentials, or environment files.

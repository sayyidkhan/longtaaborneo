# Resource Materials

## Motion and Website Inspiration

### Janustiu — Motionsites AI

- [Instagram reel](https://www.instagram.com/reel/Da0GgfHuCRr/?igsi=enNiZTh2M3hoY3k2)
- Study note: cinematic AI website effects can use looping hero videos instead of complex WebGL. Use one strong video moment; repeated video backgrounds create load-time risk.

### originkit.dev

- [Instagram reel](https://www.instagram.com/reel/DcbmdBdOItH/?igsi=MThzZW5ydnlhdjQzbQ==)
- [Component library](https://www.originkit.dev/docs/components)
- Study note: provides customizable animated components for Framer, React, Next.js, Vite, CLI, and MCP workflows. Select a few coherent components and test desktop, tablet, and mobile states before use.

### Scroll Craft

- [GitHub repository](https://github.com/nateherkai/scroll-craft)
- [Instagram reel](https://www.instagram.com/reel/DccOtyol3sf/?igsi=MWN0YTRheWhvd2w2eQ==)
- [LinkedIn resource](https://lnkd.in/p/gsuPQAiU)
- Study note: treats scroll as the storytelling timeline, requires a unique interaction and one engineered emotional peak, and verifies the final page through screenshots and interaction checks.

### Image to 3JS — 3D Modelling

- [GitHub repository](https://github.com/img2threejs/img2threejs)
- [Instagram reel](https://www.instagram.com/reel/DcY6-PRji1y/?igsi=MTk4NjZiMm4zcjZ3cw==)
- Study note: reconstructs a reference image as a procedural, animation-ready Three.js model. This is optional and should only be used when 3D strengthens the Long Taa story without hurting performance or delivery speed.

### threeUI

- [Living Green hero example](https://threeui.com/hero/sylva/living-green)
- [Instagram reel](https://www.instagram.com/reel/DcdzwM5IHNk/?igsi=MWgwaWw1NHhlcnRxMQ==)
- Study note: provides copy-ready 3D sections and templates. The forest-oriented Living Green direction fits the project, but should be adapted around authentic Long Taa photography and brand assets.

## Tools and Platforms

- [Podium](https://podium.global/)
- Study note: reference for cinematic full-bleed imagery, disciplined editorial typography, story-led pacing, and confident calls to action.
- [Lenis](https://lenis.dev/)
- Study note: lightweight smooth scrolling designed to retain native scrolling and accessibility. Use with a reduced-motion fallback.
- [Rive pricing](https://rive.app/pricing)
- Study note: supports interactive vector animation, state machines, responsive layouts, and web runtimes. Keep optional unless a small logo or journey animation adds clear value.

# Judging Criteria

Each criterion is scored from **1 to 5**.

1. **Business Understanding & Relevance**
   - Does the solution address the beneficiary's real business challenge?

2. **Website Design & User Experience**
   - Is the 5-page website clear, usable, and visually coherent?

3. **AI-Assisted Execution & Functionality**
   - Does the live website demo function as intended?

4. **Business Value & CTA Effectiveness**
   - Can it create value and move visitors to act?

5. **Presentation & Solution Communication**
   - Did the pitch and Q&A communicate the solution and impact?

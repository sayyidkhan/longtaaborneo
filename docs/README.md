# Documentation Guide

Use this folder in the following order when updating the website, chatbot, pitch, or marketing copy.

## Implementation Source of Truth

1. `website-requirements-answers.md` — agreed audience, customer decision flow, planner/chatbot rules, assumptions, and outstanding questions for Clement.
2. `website-requirements-document.md` — website structure, content requirements, UX behaviour, CTAs, and acceptance criteria.
3. `execution-plan.md` — delivery priorities and how the requirements support the hackathon submission.

If these files appear to conflict, use the status labels in `website-requirements-answers.md`: **Confirmed**, **Agreed working assumption**, **Recommended**, and **Needs confirmation**.

## Original Business Sources

The following files preserve the materials supplied by Long Taa and should not be silently rewritten to match later website decisions:

- `LONG TAA BORNEO ECO STAY.docx` and its converted Markdown copy.
- `LONG TAA BORNEO ECO STAY brochure.docx` and its converted Markdown copy.
- `Poster.docx`, `Pix.docx`, `logo.docx`, and their converted Markdown/asset files.

Use them as evidence for business facts, imagery, rates, package names, and original wording. Where a source is ambiguous, record the implementation decision or question in `website-requirements-answers.md` instead of altering the source.

## Supporting Project Documents

- `judging-criteria.md` — assessment criteria only.
- `resource-materials.md` — design and technology references only.
- `submission-list.md` — final URLs and submission checks.

## Current Customer Flow

1. Choose preferred date, guests, and nights; suggest 3 Days 2 Nights as a flexible starting point.
2. Choose accommodation only or accommodation with local meals.
3. Choose exactly one experience: Package 1 or Package 2.
4. Choose Long Taa's return 4WD, or request approval for an own terrain-suitable 4WD; then state whether river/activity support is required.
5. Review an itemised indicative estimate and assumptions.
6. Request availability, itinerary, and a confirmed quotation through WhatsApp.

The flow must not imply an online purchase or confirmed reservation.

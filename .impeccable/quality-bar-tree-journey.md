# Tree Journey — quality bar

- Memory test: the tree is the navigation; the visitor descends from canopy, through branch stories, to roots and a warm longhouse threshold.
- Material: rainforest black-green, leaf-light green, rough timber, warm doorway light, restrained glassless editorial panels.
- Type: Bodoni Moda for story-scale headings; Manrope for navigation and practical details; compact uppercase text is metadata after content, not a default heading kicker.
- Motion: one reversible camera journey tied to scroll, with no ornamental UI animation and a reduced-motion path.
- Interaction: visible current-stage label, branch-to-card connector, one persistent route to the booking conversation, keyboard-safe inactive stages.
- Mobile bar: the tree must remain legible behind translucent content; header, menu, stage state, scroll rail, and booking card must fit without horizontal clipping.
- Content truth: all Long Taa claims, photographs, routes, contact details, and calls to action remain the existing site’s own information.
